# Vendored anti-slop lint rules

The generic lint rules in this directory originate from
[dmmulroy/anti-slop](https://github.com/dmmulroy/anti-slop), revision
[`6d538555cb151d4121ed51a27db81890eacf8ae9`](https://github.com/dmmulroy/anti-slop/tree/6d538555cb151d4121ed51a27db81890eacf8ae9),
as recorded in the project's original development notes.

This is a selected subset wired into Shortcut Shepherd's oxlint configuration, not a complete
upstream checkout. Upstream's optional Effect rules are not included.
